# Account access and closure candidates

Access/session tools can change real access and revoke sessions. Read-only
preflight inventories blockers without authorizing deletion. App 0.5.0 and
approver 0.3.0 require coordinated integration and remain candidates. Review
[work configuration](../../docs/work-configuration.md) before service use.

Offline fixtures/mocks:

```sh
PYTHONDONTWRITEBYTECODE=1 python3 -m unittest discover -s host/account -p 'test_*.py' -v
```

See [lab guidance](../../docs/lab-validation.md) for PHP mocks and opt-in lab
prerequisites. Populated upgrade uses explicit `COVIN_LAB_BASELINE_DIR` and the
pinned external 0.4.0 source, never work main. The manifest/helper verifies bytes,
modes, version and paths before Docker. The sibling reference is outside work Git.

Normal host CLI access requires ACCOUNT_PLATFORM_RUNTIME_REVIEWED=1 after target/policy review. Lab creation is separately isolated and requires explicit reviewed image IDs.
